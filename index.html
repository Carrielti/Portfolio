Conhecimento aplicado à soluções reais

Tenho interesse principalmente em desenvolvimento web, automação e criação de sistemas, buscando transformar problemas do cotidiano em soluções através da programação.

03 - PROJETOS


Projetos em Destaque

Uma seleção dos meus projetos mais recentes, desde projetos Web até projetos Mobile.

EcoMap - descarte consciente mais perto de você

Sistema que utiliza a localização do usuário para encontrar os pontos de coleta de pilhas mais próximos, facilitando o descarte correto e incentivando práticas sustentáveis.

HTML CSS JavaScript PHP Leaflet MySQL Geolocalização

OfertMatch — encontre as melhores ofertas perto de você

Plataforma desenvolvida para ajudar o usuário a encontrar produtos, empresas e ofertas próximas, facilitando a comparação de preços e a escolha das melhores opções disponíveis.

HTML CSS JavaScript Python Flask MongoDB Geolocalização API REST

ExpenSelf — controle financeiro de forma simples e inteligente

Sistema desenvolvido para ajudar o usuário a registrar receitas e despesas, acompanhar o saldo mensal, organizar gastos por categorias e visualizar sua evolução financeira por meio de gráficos e metas.

HTML CSS JavaScript PHP MySQL Python Flask

Orby — produtividade e organização em um só lugar

Aplicativo desenvolvido para ajudar o usuário a organizar atividades, compromissos, hábitos e finanças, reunindo ferramentas de produtividade e controle pessoal em uma única plataforma.

React Native TypeScript Node JSON Android Expo
